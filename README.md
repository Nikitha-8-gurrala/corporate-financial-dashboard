# Corporate Financial & Margin Performance Dashboard

## Project Overview
This project was developed as Task 4 of the DATHEON Data Analytics & Power BI Internship. It provides an interactive dashboard to analyze corporate financial performance, revenue, costs, profitability, and budget variance.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Microsoft Financial Sample Dataset

## Key Performance Indicators

| Metric | Value |
|---|---:|
| Gross Sales | $127.93M |
| Total Discounts | $9.21M |
| Net Sales | $118.73M |
| Cost of Goods Sold | $101.83M |
| Gross Profit | $16.89M |
| Gross Profit Margin | 14.23% |

## Dashboard Features
- Corporate Income Statement
- Revenue to Gross Profit Waterfall Analysis
- Quarterly Financial Performance
- Profit Margin by Business Segment
- Actual vs Simulated Budget Sales
- Interactive Year and Country Slicers

## Key Business Insights
- Channel Partners recorded the highest gross profit margin of 73.13%.
- The Enterprise segment recorded a negative margin of 3.13%.
- Q4 2014 recorded the highest quarterly net sales among the available quarters.
- Cost of Goods Sold represents the largest deduction from revenue.

## Strategic Recommendations
- Review pricing and costs in the Enterprise segment.
- Explore growth opportunities in high-margin business segments.
- Optimize discount strategies to protect profitability.
- Monitor quarterly financial performance and budget variance.
